## Nouveautés

- **Sauvegarde chiffrée** : dans Paramètres → Sauvegarde, enregistre toutes les données de CarDeck dans un fichier chiffré (AES-256) que seule l'application peut relire : véhicules, boîtiers associés, trajets, diagnostics, codages d'origine et réglages.
- **Restauration** : remplace les données par celles d'une sauvegarde, après confirmation. Un fichier endommagé, modifié ou incomplet est refusé sans rien toucher.
