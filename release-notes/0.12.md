## What's new

- 🧮 **Decoding leads over the whole drive** (Contribution): at the end of a recording while driving, every byte and pair of bytes of the manufacturer blocks and of the CAN bus frames is compared with the OBD values measured at the same moment, over the whole trip. Counters are set aside, the small time lag is taken into account, and each lead comes with its formula (for example "speed ≈ x / 100"). The leads appear in the report, on the Contribution page and in the GitHub issue, and older recordings are analysed too. Method adapted from CANExplorer.
- 🔧 **K-line modules no longer missed**: some modules wake up at one address but only answer messages sent to another one (like the VW MK60 ABS: 03 → 28). The explorer now finds that address instead of giving up on the module. VW wake-up addresses have been added to the search.
- 🌍 "Other vehicle" is now translated in the vehicle picker.
