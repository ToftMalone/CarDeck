## What's new

- 🗄️ **Back up to your own server (SMB)**: in Settings › Backup, set up a NAS, PC or box on your network, test the connection, then back up to it and restore from its list of backups. Exchanges are signed and the server password is stored encrypted on your phone, never inside a backup.
- 🔐 **Simpler backups**: backups are now either encrypted by CarDeck or unprotected. Password and device-bound protection are gone (older backups using them can still be restored). Original codings are no longer saved in new backups.
- 🔤 **Alphabetical vehicle list**: models are sorted alphabetically in every brand, and generations from oldest to newest.
- 🔧 **"Reverse-engineered" badge**: the badge on vehicles whose manufacturer data CarDeck has decoded is back to the check mark, and now reads "Reverse-engineered".
- 💥 **Knock search** is now offered only on the Suzuki Swift Sport ZC33S, the only car reverse-engineered for it.
